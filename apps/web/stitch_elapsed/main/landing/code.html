Questions & Answers

Frequently asked questions

Is Elapsed read-only? +

Yes, completely. Elapsed requests read-only OAuth scopes from Zendesk, Intercom, Jira, Linear, and GitHub. It cannot modify ticket tags, alter statuses, append comments, or create issues in any connected workspace.

How fresh is the data? +

Webhooks process state changes within milliseconds. In the event of webhook delivery delays from third-party APIs, a background daemon reconciliation loop audits open cases every 120 seconds to guarantee data freshness.

How does Elapsed know which Jira issue belongs to a ticket? +

Elapsed checks multiple deterministic links: native Zendesk-Jira integration records, remote issue links created in Jira, and issue keys embedded within PR titles and branch references. It does not guess matches based on fuzzy text.

Does it handle business hours and holidays? +

Yes. You can define custom operating calendars with specific working hours, weekend definitions, and regional holiday dates. During non-working intervals, the SLA resolution clock pauses cleanly on the timeline.

How far back does history go? +

During initial onboarding, Elapsed syncs the last 90 days of escalated cases to construct your operational baseline immediately. Retained historical audit logs depend on your plan level (up to multi-year for custom enterprise configurations).
